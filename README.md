# Challenge viind

Die Seite wurde als Next.js Web-App umgesetzt. Sie verfügt über eine REST-API mit der Mock-Daten für einen Kunden abgerufen werden können `/api/customers`.

Die Web-App hat eine Seite auf der die Baumstruktur des Kunden dargestellt wird. Die einzelnen Knoten lassen sich aufklappen. Über einen Link kann die Seite aufgerufen werden.

```
# Dependencies installieren
npm install

# Anwendung starten
npm run dev

```
